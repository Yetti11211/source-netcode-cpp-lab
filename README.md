# Source Netcode Lab

Учебная C++-демонстрация клиентского предсказания, серверной авторизации и reconciliation для сетевого шутера в стиле Source.

## Что показано

- клиент мгновенно применяет локальный ввод;
- сервер хранит авторитетное состояние;
- снимки сервера возвращаются с задержкой;
- клиент находит подтверждённую команду, исправляет позицию и повторяет неполучившиеся команды.

Откройте NetcodeLab.cpp в Visual Studio 2022 или соберите любым компилятором с поддержкой C++17:

```powershell
cl /std:c++17 /EHsc NetcodeLab.cpp
```
